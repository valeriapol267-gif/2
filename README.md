# depviz

Инструмент визуализации графа зависимостей Maven-пакетов (Java).
Практическая работа №2 по дисциплине «Конфигурационное управление»,
вариант 22.

## 1. Общее описание

`depviz` - консольное приложение на Python (стандартная библиотека, без
сторонних зависимостей). Менеджеры пакетов и готовые библиотеки для
получения зависимостей не используются.

Состояние проекта: **этап 1 - минимальный прототип с конфигурацией**.
Приложение принимает параметры из командной строки, проверяет их и выводит
в формате «ключ: значение».

## 2. Описание настроек

Все параметры задаются опциями командной строки.

- `--package` - имя анализируемого пакета `groupId:artifactId`.
  В тестовом режиме - имя из больших латинских букв (`A`, `B`, ...).
  Обязательный параметр.
- `--repo` - URL Maven-репозитория или путь к файлу тестового репозитория.
  По умолчанию `https://repo1.maven.org/maven2`.
- `--test-mode` - режим тестового репозитория: `--repo` задаёт путь к
  файлу. По умолчанию выключен.
- `--version` - версия пакета. Обязательна вне тестового режима.
- `--output` - имя файла с изображением графа (расширение `.png`).
  По умолчанию `graph.png`.
- `--max-depth` - максимальная глубина анализа, целое от 1 до 100.
  По умолчанию `3`.

Проверки параметров:

- `--package`: вне тестового режима - строго `groupId:artifactId`
  (латиница, цифры, `_`, `.`, `-`); в тестовом режиме - только `A-Z`.
- `--repo`: URL со схемой `http`/`https` и хостом; в тестовом режиме -
  существующий читаемый файл (параметр обязателен).
- `--version`: непустая строка из букв, цифр и `_ . + -`, начинается с
  буквы или цифры.
- `--output`: расширение `.png`, без недопустимых символов, каталог должен
  существовать, имя не может быть каталогом.
- `--max-depth`: целое число в диапазоне 1-100.

При ошибке сообщение выводится в stderr, код завершения - `2`.

## 3. Запуск и тесты

Требуется Python 3.9+.

```
sh run.sh --package org.apache.commons:commons-lang3 --version 3.14.0
run.bat   --package org.apache.commons:commons-lang3 --version 3.14.0
```

Тесты (стандартный `unittest`):

```
python3 -m unittest discover -s tests -t . -v
```

В PyCharm каталог `src` нужно пометить как Sources Root.

## 4. Примеры

```
$ sh run.sh --package org.apache.commons:commons-lang3 --version 3.14.0
package: org.apache.commons:commons-lang3
repo: https://repo1.maven.org/maven2
test-mode: false
version: 3.14.0
output: graph.png
max-depth: 3
```

Тестовый режим:

```
$ sh run.sh --test-mode --package A --repo repo.txt
package: A
repo: repo.txt
test-mode: true
version: -
output: graph.png
max-depth: 3
```

Обработка ошибок:

```
$ sh run.sh --package commons-lang3 --version 1.0
Ошибка параметров: имя пакета должно иметь вид groupId:artifactId: 'commons-lang3'.

$ sh run.sh --package a:b
Ошибка параметров: не задана версия пакета (--version).

$ sh run.sh --package a:b --version 1.0 --repo ftp://x
Ошибка параметров: URL репозитория должен иметь вид http(s)://хост/путь: 'ftp://x'.

$ sh run.sh --package a:b --version 1.0 --max-depth 0
Ошибка параметров: максимальная глубина должна быть от 1 до 100: 0.

$ sh run.sh --package a:b --version 1.0 --output graph.svg
Ошибка параметров: имя файла изображения должно оканчиваться на .png: 'graph.svg'.

$ sh run.sh --test-mode --package a --repo repo.txt
Ошибка параметров: имя пакета в тестовом режиме должно состоять из больших латинских букв (A, B, ...): 'a'.

$ sh run.sh --test-mode --package A --repo none.txt
Ошибка параметров: файл тестового репозитория не найден: 'none.txt'.
```
